# Sprint 1 — Sprint Planning
•	Sprint 1 Goal: 
-	The goal of Sprint 1 is to plan the main features of EchoEats which is an application that helps restaurants, cafes and bakeries sell surplus food instead of wasting it
-	During this sprint the team will define how vendors can list and manage their food while consumers can find nearby discounted food, view prices and reserve meals for pickup
-	Our focus will be on the dynamic pricing system which automatically lowers food prices as expiration approaches while considering customer demand and minimum price set 
-	By end of Sprint 1 we aim to have clear requirements an initial system architecture and wireframes for main screens. We will use feedback to improve our work and prepare for developing EchoEats in the next 2 sprints
•	List EchoEats user stories/features selected for initial requirements / design work:
Consumer User Stories:
1.	US-C01 / Registration and Login: As a consumer, i want to create an account and log in so that I can use EchoEats and manage my reservations.
2.	US-C02 / Find Nearby Discounted Food: As a consumer, I want to find discounted food from nearby vendors on a list or map so that I can buy affordable meals close to me.
3.	US-C03 / Search and Filter Food: As a consumer, I want to search and filter available food based on my preferences so that I can easily find what I'm looking for.
4.	US-C04 / View Food Details - Current Dynamic Price: As a consumer, I want to view food details and current updated price so I can compare deals before making a purchase.
5.	US-C05 / Reserve Food: As a consumer, I want to reserve available food so I can collect it before it expires or sells out.
6.	US-C06 / Payment and Pickup Information: As a consumer, I want to pay for my reserved food and receive pickup details so I can complete my purchase and collect order
Vendor User Stories:
1.	US-V01 / Vendor Registration and Login: As a vendor, I want to register for an account and securely log in so that I can access and manage my surplus food listings and orders.
2.	US-V02 / Creating Surplus Food Listings: As a vendor, I want to create food listings with the item's name, description, category, quantity, price, expiration time, and collection deadline so that customers can view and reserve available surplus food.
3.	US-V03 / Editing Listings and Managing Quantities: As a vendor, I want to edit my food listings and update available quantities so that customers see accurate information and cannot reserve food that is no longer available.
4.	US-V04 / Setting Initial/Minimum Selling Prices: As a vendor, I want to set initial price/minimum price for each listing so I control starting price(lowest price system apply)
5.	US-V05 / Automatic Price Reductions as Expiration Approaches: As a vendor, I want food prices to automatically decrease as collection deadline approaches, while considering customer demand and my minimum price, so I can sell more surplus food.
6.	US-V06 / Managing Reservations and Pickups: As a vendor, I want to view and manage customer reservations, track their status, and confirm pickups so I can prepare orders.
